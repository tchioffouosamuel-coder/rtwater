✨ FONCTIONNALITÉS PRINCIPALES
═════════════════════════════════════════════════════════════════════════════

📊 DASHBOARD
   ├─ Stats principales (ventes, commandes, stock)
   ├─ Activités récentes
   └─ Actions rapides

📦 GESTION DU STOCK
   ├─ Dashboard avec statistiques
   ├─ Alertes stock critique (< 5 unités)
   ├─ Alertes stock faible (< min)
   ├─ Liste inventaire avec:
   │  ├─ Quantité
   │  ├─ Min/Max
   │  ├─ Coût unitaire
   │  ├─ Valeur totale
   │  └─ Emplacement physique
   ├─ Mouvements (entrées/sorties)
   └─ Historique par produit

💳 POINT DE VENTE (POS)
   ├─ Catalogue produits interactif
   ├─ Panier avec:
   │  ├─ Ajout/Retrait articles
   │  ├─ Gestion quantités (+/-)
   │  └─ Suppression items
   ├─ Calculs automatiques:
   │  ├─ Sous-total
   │  ├─ TVA 20%
   │  └─ Total
   ├─ Paiement multi-méthode:
   │  ├─ Espèces
   │  ├─ Carte
   │  ├─ Chèque
   │  └─ Virement
   ├─ Calcul monnaie rendue
   ├─ Génération reçu automatique
   └─ Impression directe

🧾 REÇUS & TRANSACTIONS
   ├─ Vue jour avec:
   │  ├─ Nombre transactions
   │  ├─ Montant total
   │  ├─ Panier moyen
   ├─ Liste transactions avec:
   │  ├─ ID & Heure
   │  ├─ Articles (Qté)
   │  ├─ Montant
   │  └─ Méthode paiement
   ├─ Détails transaction:
   │  ├─ Articles détaillés
   │  ├─ TVA
   │  ├─ Total
   │  ├─ Paiements
   │  └─ Monnaie
   ├─ Actions:
   │  ├─ Afficher détails
   │  ├─ Réimprimer
   │  └─ Télécharger (PDF Phase 2)
   └─ Format reçu HTML optimisé

│  ├─ receipts: Receipt[]                                       │
